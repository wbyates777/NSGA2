# NSGA2 - A Multiobjective Evolutionary Algorithm

Two implementations of: "A Fast and Elitist Multiobjective Genetic Algorithm: NSGA-II".

Use this algorithm to optimise problems with multiple objectives. Outputs a Pareto front of solutions.

I have included the original paper for completeness.

This version implements constraint handling.

Python MOEA tested on Python versions 3.8 to 3.13.

C++ MOEA depends soley on STL, tested on c++20.
